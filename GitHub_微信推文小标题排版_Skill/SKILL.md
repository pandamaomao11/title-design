# Premium Real Estate WeChat Title Layout Skill

## Purpose

用于生成高端地产、顶豪项目、品牌价值传播类微信公众号推文小标题排版。

注意： - 这是微信推文小标题，不是画册章节页。 -
强调阅读性、品牌感、信息层级。

## Visual Style

关键词： - 高级地产 - 现代东方 - 克制 - 留白 - 品牌感 - 轻奢但不浮夸

整体： - 白色或浅色背景 - 大面积留白 - 简洁结构

## Fixed Color System

Primary: - 深墨绿 - 青绿色渐变 - 香槟金

Secondary: - 半透明青绿色光晕 - 柔和圆形渐变 - 极细金色线条

Avoid: - 高饱和色 - 复杂纹理 - 大面积背景渐变 - 过多装饰元素

## Layout Components

### Number System

支持： - Part 01 - 01. - 02

数字位置： - 标题右侧 - 标题左侧 - 标题上方 - 标题下方

数字需要作为视觉锚点。

### Circle Light Element

使用： - 青绿色透明圆 - 柔和渐变光球

表达： - 光 - 生机 - 自然 - 未来感

不要： - 使用过大的装饰圆形 - 影响文字阅读

### Line System

使用： - 极细金线 - 水平延展线 - 简洁分割线

作用： - 建立秩序 - 增加高级感

避免： - 复杂框架

## Typography

Chinese: - 高级宋体 - 现代黑体结合

English: - 细衬线字体 - 小字号辅助

Numbers: - 优雅衬线数字

## Information Hierarchy

Level 1: 核心价值标题

Level 2: 解释性副标题

Level 3: 英文辅助信息

保持： - 主标题突出 - 副标题清晰 - 留白充足
